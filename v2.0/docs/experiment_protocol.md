# ReCAD v2 实验方案：以独立验证决定模型

日期：2026-09-05。状态：实验设计草案已落地；尚未冻结数据清单、运行正式比较或开启独立验证。

## 1. 科学问题与判定范围

比较单点回归、多尺度时空 CNN/U-Net、ST-Transformer 对月尺度 0.125° 沿海 fCO2、SSS、TA、DIC 重建的贡献。分别检验时空背景、多任务监督、Carter TAest 和化学约束，避免一次改变多个因素后将提升都归于 Transformer。

主要结论来自未参与模型、先验、超参数或报告规则选择的独立观测。低训练误差、内部随机划分成绩、化学闭合良好均不能替代独立 TA/DIC 验证。NACCOM 是第一阶段区域实验，其结论不能直接宣称适用于全球沿海。

首轮研究固定为条件回归：推理输入环境场，不输入任何目标观测。后续若引入观测同化，应作为单独实验，所有模型使用同一可用观测集合，评估点不得进入同化。

## 2. 已核实的现状与缺口

- 现有 NACCOM 配置：网格样本随机 80/20，2004–2005 整年 test；这不是本方案要求的独立验证。
- SOCAT/GLODAP 的点级脚本分别按航次分割，未共享跨数据库航次组；按测试年份先分行也可能切开跨年航次。
- 当前海岸 mask 来自有观测格点，可能排除从未被观测的独立验证位置。正式产品区域应使用预先固定的地理海岸掩膜；对范围外点单列报告。
- 当前有效样本取决于 fCO2 是否存在，不能直接用于多任务训练，否则缺少 fCO2 的 TA/DIC 锚会被排除。
- 当前指标名 r2 实际为 Pearson r 的平方。正式评估增加 R2=1-SSE/SST，保留旧指标但重命名为 pearson_r_squared。
- 本地 ESPER README 提及重新拟合 GLODAPv2.2020 子集。实际 MAT 系数文件的训练清单、版本和日期仍待审计，不能直接把 GLODAP 留出点称为对整个系统独立。
- 仅读取 GLODAP 表层表的坐标、年份和航次元数据：全球 14,930 行/592 航次；NACCOM 矩形内 2,158 行/79 航次。这里不是 QC 后有效 TA/DIC 标签数，也未应用最终地理掩膜。
- NACCOM 2004–2005 仅 42 行/3 航次；2020–2021 仅 181 行/3 航次。因此不能简单把最近两年或 2004–2005 当成有充分统计把握的 TA/DIC 独立验证。
- 缓存时间轴延伸至 2026-12，不表示所有变量该月实际可用。正式共同覆盖时段须由元数据审计确定；不得插补标签或把未来空月份计作验证样本。

## 3. 数据分层：training / test / independent validation

### 3.1 三层外部划分，training 内部再分 fit/dev

| 集合 | 用途 | 是否可影响模型选择 |
|---|---|---|
| training-fit | 梯度、标准化、经验修正、数据驱动先验拟合 | 是 |
| training-dev | early stopping、超参数、loss 权重、区间校准、候选排序 | 是；属于 training 开发池 |
| test | 冻结候选后一次内部泛化检查；2004–2005 历史比较属于此层 | 不用于本轮调参 |
| independent-validation | 最终盲验证：确认事先提出的模型比较与科学结论 | 否 |

先排独立验证，再排 test，最后分 fit/dev。独立集数量由独立航次/站点、变量和环境覆盖决定，不机械分配 20% 的观测行。

test 默认保留 2004–2005 以对齐历史，并额外从剩余开发数据按元数据分层保留约 15% 航次连通组作为 test-grouped，以弥补锚点过少；两者分开报告。剩余 training 池采用 3 折分组/分块交叉验证，每折约 2/3 fit、1/3 dev。独立验证和 embargo 优先级最高。最终成员在全 training 池重训，训练轮数由开发折最佳轮数的中位数确定，不再 early stop 于 test。

若观察 test 后修改算法，该 test 变为开发证据，记录新轮次；不可继续宣称未使用它选择模型。独立集开启后禁止根据其结果修改本轮模型、阈值、排除规则。若需要新迭代，需新独立集。

### 3.2 独立验证需要回答三个不同问题

1. IV-external（主验证）：新的独立航次、系泊/时间序列或项目，来源和样本均未进入 ReCAD 拟合/调参，也未进入所用 Carter 系数拟合。优先收集明确的实测 fCO2、S、TA、DIC，不能用 TAest 或由 CO2SYS 派生的 DIC 充当直接观测。不同变量可以来自不同独立观测组，但各自标注覆盖和独立性。
2. IV-space（空间转移挑战）：按海洋学区域预先固定整个沿海子区，所有年份、所有目标变量标签统一移除；多个子区分别报告。区域选择只看地理、航次/时间/变量可用性，不看标签分布或模型误差。若缺少独立 TA/DIC，不将 fCO2 空间成绩外推为碳系统验证。
3. IV-time（时间转移挑战）：预先固定连续末期年份，所有区域及目标标签移除，并去掉相邻时间缓冲。若只在 NACCOM 移除，称区域时间转移，不称全球时间外推。实际年份由有效覆盖和先验训练谱系决定，当前不武断指定 2020–2021。

三套验证可以有相交观测，但必须去重并报告交集，不能当作三个独立重复或简单合并置信区间。盲留出挑战能验证指定泛化情景，不等同于观测来源独立。暂时找不到符合条件的 IV-external 时，可继续开发，但最终结论标为“内部留出/挑战验证”，不得替换成“完全独立”。CODAP 是候选来源，需先获取、去重并核对其是否进入 GLODAP/ESPER，数据库名称不同不代表独立。

### 3.3 防止直接与间接泄漏

- 建立跨 SOCAT/GLODAP/外部来源统一样本谱系表。规范化 expocode、船次别名、站号、采样时空和深度，连接已知同航次/同水样/数据库重复；整个连通组同属一层，包括跨年航次。
- 独立观测组内的所有目标标签一同留出。不能用独立 TA 对应的 fCO2 或盐度训练，再称 TA 独立。标签衍生特征、目标气候态、拟合先验和同化输入同样屏蔽。
- 在原始点级完成分割，再分别构建训练、开发和评估目标。禁止先将同一格月的不同集合平均在一起；不同航次同格月也需合并分组或将冲突训练样本移入 embargo。
- IV-external 周围初始排除训练标签：海洋距离 <=100 km 且时间差 <=31 天。IV-space 外缘初始排除 100 km 训练标签；IV-time 边界初始排除 3 个月。仅用 training 的相关尺度诊断调整，正式训练前冻结；开发期对 50/100/200 km 和 1/3/6 月做敏感性检查。沿岸距离/跨陆地邻接使用海洋连通约束。
- 固定物理 QC 可用于所有集合；基于标签分布的 outlier cutoff、气候态、去趋势和标准化仅拟合 training-fit。独立集不做基于预测误差的剔除。
- TAest 只能用推理可用的背景场计算，不得用被留出的现场 S/T 生成更好的输入。ESPER 版本、方程和 MAT 文件哈希固定；要证明系数未见独立样本，否则重拟合训练专属先验、使用无 TAest 路线或另找独立样本。
- 对再分析 SSS 等背景产品审计同化来源。若独立盐度观测可能已被 GLORYS 同化，报告“相对于 ReCAD 标签独立，背景同化独立性未证实”；另设可审计的严格子集。完全独立是信息链属性，不能仅靠 split 字段保证。
- 环境场可在历史重建时使用目标月份和双向时间上下文，这不等于使用目标标签；时间转移结果不称作实时预报。所有模型使用相同可用场、缺测标记和冻结归一化。
- 只看独立集元数据选择覆盖；标签不交给训练脚本。独立标签置于隔离评估路径，冻结 manifest 和哈希。当前没有用户外部保管机制时，这是工程盲评，不声称已经做到组织层面的第三方盲评。

## 4. 模型与消融矩阵

统一基础输入：SST、SSS_bg、ADT、pCO2air、wspd、经纬度、月份。相同日历信息；是否加入绝对年份作为预先规定的共同消融，不能只给某一骨干。TAest 作为后续共同因素。

### 阶段 A：仅预测 fCO2，隔离骨干效果

| ID | 模型 | 目的 |
|---|---|---|
| A0 | training 专属区域/月气候态 | 最低技能参照；无训练覆盖时有固定回退规则 |
| A1 | 随机森林 | v1 家族强基线；用相同数据重训，不直接比较不同样本上的历史数字 |
| A2 | 单点 MLP | 非线性单点回归 |
| A3 | 多尺度空间 CNN/U-Net + 时间模块 | 学习局地形态、邻近月份背景 |
| A4 | 现有 ST-Transformer | 学习 patch 间及时序联系 |

A2–A4 使用相同 fCO2 损失、归一化和采样权重，第一轮采用 MSE 点估计。CNN/Transformer 均使用 12 个月上下文，相同月份目标。边界处理冻结，记录现有按年窗口不能跨年的限制。额外在 training-dev 上做同域局地窗口比较，辨别 A4 的改善来自 attention 还是更多上下文。空间/时间上下文消融采用重训后的“本月”和“单点”版本，不仅推理时打乱造成分布外输入。

### 阶段 B：在 A2、A3、A4 上做同一组多任务对照

| ID 后缀 | 输出与约束 | 可回答的问题 |
|---|---|---|
| B0 | fCO2、S、TA、DIC；分别监督，无 TAest、无化学项 | 多任务本身是否帮助 |
| B1 | B0 + TAest 输入 | 外部经验先验是否帮助 |
| B2 | B1 + 软化学闭合 | 化学关系是否改善独立预测 |
| B3 | B1 + 硬闭合：网络输出 S、TA、DIC，fCO2 由化学层生成 | 精确化学一致性与统计拟合的权衡 |

阶段 B 共 12 个模型条件，不能只让 Transformer 使用物理约束。B1/B2 默认独立 TA 输出，另对开发集选出的骨干比较 TA=TAest+deltaTA 的残差参数化；不要将“多加输入”与“强制先验中心”混为一个实验。

每任务在自己有效标签上平均，固定 SOCAT/锚点采样与任务权重。统一输出量纲、可行范围处理。B2 闭合残差定义为 C(T,S_hat,TA_hat,DIC_hat)-fCO2_hat，在预先规定的海洋格点采样上计算；观测误差另外计算。避免重复把同一 fCO2 观测当作两份独立信息。化学常数、营养盐假设和适用范围全部固定。

噪声归一化初值沿用当前设计 fCO2:5、S:0.1、TA:8、DIC:8；这只是开发起点，不宣称等同于所有月尺度代表性误差。lambda_chem 默认候选 0.1/1/10，仅在 dev 选择；空间正则首轮关掉，后续单独消融，时间平滑默认关闭。

另报告背景 SSS、TAest 自身的独立误差，以及 A1-fCO2 + 背景 S + TAest 经 CO2SYS 求 DIC 的透明基线。它用于判断复杂联合模型是否确实超越“经验先验+化学计算”。不得将这种派生 DIC 当成训练或验证真值。

## 5. 公平训练与计算预算

- 先做小规模管线检查，不访问独立标签。单模型短跑测量吞吐/显存后冻结预算；RTX 5070 上采用分块/按需读取，不能为某一模型剔除难预测的验证位置。
- 正式开发每条件 3 个预先登记的超参数配置 × 3 个相同数据折，每次最多 60 epochs、early-stop patience 10。固定开发种子 100；所有条件采用相同数量的搜索机会。配置内容及按任务覆盖确定的采样配额在运行前入 YAML，不在独立评估后补写。
- 阶段 A 排序按 dev 航次等权 fCO2 RMSE；阶段 B 使用四变量归一化航次等权 RMSE 的算术平均，尺度仅来自每折 training 标签 std。并报告各变量，禁止以平均分掩盖严重退化。固定规则选配置，再在全 training 池重训。
- 所有最终待比较条件使用相同 5 个种子：100、101、102、103、104。分别报告单成员分布与 5 成员集成，避免 RF 单次与 Transformer 集成的含混比较；RF 明确自身已有树集成。
- 首轮用于点估计比较。概率区间采用统一、仅由 dev 残差校准的方案并标明交换性假设限制；ensemble spread 本身不等于总预测误差。原生 Gaussian head 作为后续共同扩展。
- 参数量尽量处于可比较数量级，但不声称相同参数量代表相同能力。记录参数量、训练小时、峰值 RAM/VRAM、推理吞吐、有效样本数和失败率。对少量候选做相同 GPU 小时预算的次级比较。
- 所有正式候选及配置冻结后一起生成 test/独立集预测并保存哈希，随后统一评分。独立结果不参与筛选种子或成员。若事先指定的主模型失败，结论为未证实；不把盲集赢家重新包装成事前主模型。

## 6. 验证对象、指标与统计判断

### 6.1 观测与月场匹配

主科学目标是 0.125° 月尺度场。评估先按独立航次-格点-月份聚合其观测，保存点数、采样天数、标准差和标准误；同一格月不同航次另算等航次权均值，防止高频船测支配结果。匹配算子（格内常值为主、双线性为次）训练前固定，所有模型相同。另报告逐点匹配误差，但明确包括月内/格内代表性误差。

月内覆盖充分的独立系泊/时间序列作为月平均验证子集。只有单次采样的 TA/DIC 不能被描述为可靠实测月平均场，应称独立表层采样匹配。表层 <=5m 为主，其他深度只作预先登记的敏感性分析。

### 6.2 每个变量分别报告

- RMSE（原始单位）、MAE、bias、真正 R2=1-SSE/SST；Pearson r 和 r² 作为补充。
- 主 RMSE 为先算各航次 MSE、等航次平均再开平方；同时报告格月权重和逐点权重结果。系泊以站点为独立组，单独分层报告。
- 明确 N 原始观测、N 航次/站点、N 格月、区域/年份/季节覆盖。缺测标签各自 masked，不能要求四标签同时存在。
- 分区域、季节、盐度背景分层、距岸带、训练覆盖距离报告；边界仅由地理标准或 training 分位数事先确定。异常和趋势技能以 training 气候态为基准，只在独立时间覆盖支持时报告。
- 区间若输出：50/80/95% 覆盖率、区间宽度、适用时 CRPS；不能仅报告 ensemble spread。
- 化学残差与不合理状态率作为一致性诊断，硬闭合的零残差不计作预测技能。
- 预测缺失不得静默丢弃。主比较采用预先固定的共同可评估样本，同时对整个合格独立集合报告覆盖率和失败位置；某模型选择性失败时，不给出无条件优胜结论。

### 6.3 配对统计与成功标准

对同一独立样本集合做配对比较，以完整航次/站点为 bootstrap 单位，2,000 次，给出指标差的 95% CI。存在同事件/邻近航次相关时用更高层区域-时间块聚类，并报告簇数；不得 bootstrap 数百万观测行来制造虚假的窄区间。

事先登记主比较：A4 对 A3 的 fCO2 主 RMSE；B2 对 B1 的四变量指标；B3 对 B2 为次级。多个确认性比较使用 Holm 修正（alpha=0.05）。其余分层分析标记探索性。

暂定实用改善阈值为主 RMSE 相对下降 >=5%，且配对置信区间支持改善；这是项目决策阈值，不是领域通用标准。联合模型还要求其他变量无明确 >5% 退化。非劣结论需要差值区间的上界落在 +5% 内，“未显著变差”不等于非劣。更快更简单的模型在误差证据接近时优先。

在 training-dev 残差与独立集组数元数据上做功效/最小可检测差异估计，冻结后再开盲。若 TA/DIC 只有少数航次，报告不确定性和证据不足，不因未显著而宣称模型等价。5 个种子不能替代独立航次数。

## 7. 月平均闭合与可辨识性附加检查

在 training 专属的同步高频数据上量化 mean(C(z))-C(mean(z))；没有这样的数据时，只能用明确标记的模拟敏感性实验，不能称实测证实。软/硬约束两条路线的选择以 dev 决定，独立验证确认。

在代表性 training 状态上分析 CO2SYS 对 TA/DIC/S 的灵敏度和补偿方向。报告 TA/DIC 独立误差、联合误差相关和锚点距离性能；检验是否出现 fCO2 变好但 TA/DIC 相互补偿且更差。留出锚点的标签不得用于该分析选状态或调权重。

## 8. 实施顺序与产物

1. 数据审计：原始点元数据清单、跨来源去重表、ESPER/GLORYS 谱系、共同覆盖时段、独立候选来源。当前仅部分完成。
2. 冻结集合：split_manifest.parquet、split_protocol.yaml、exclude/embargo 原因、来源/配置哈希；生成仅含元数据的覆盖报告。清单未冻结前不运行正式模型比较。
3. 实现统一点级/格月观测算子、多任务样本池、training-only 统计，以及无标签泄漏的地理掩膜。
4. 实现必要测试：跨库/跨年航次不跨层；同格月不跨层；缓冲有效；独立标签改变不影响训练产物；CO2SYS 前向和梯度验证；真实 R2 与缺失预测处理。
5. 运行 A，再运行 B 的开发实验；冻结候选、预算、主比较、评分规则，生成 lock.json 和 checkpoint/prediction hashes。
6. 统一 test 检查并记录；无方法修改后执行独立盲评。任何修改按新轮次记录，保留原始结果。
7. 输出 experiments.csv、predictions.parquet、metrics_by_variable.csv、metrics_by_group.csv、paired_comparisons.csv、independence_audit.md、final_report.md。每行结果可追溯 split/config/code/data hashes。

当前预处理产物仅供工程检查，原有 masks 和已使用全部标签拟合的统计不可用于正式独立实验。尚未获得或确认严格 IV-external；本方案不虚构独立数据已经存在。

## 8.1 Reviewer-ready 实验归档门槛（强制）

任何支撑科学结论的正式实验，包括未通过门槛、负结果和失败实验，只有在 `docs/experiment_archive/<experiment_id>/` 建立可复核归档并通过自动校验后才能标记 `complete` 或关闭对应 Issue。工程 smoke/MVP 若不用于科学结论可以不归档；一旦被报告或用于选择路线，也必须补齐归档。

每个归档至少包含：

- `REPORT.md`：完整记录科学问题、允许的结论、数据与 split、泄漏控制、模型、训练与选择规则、全部主要指标、分层结果、不确定性、偏离项、负结果和限制；
- `figures/`：可直接用于 reviewer 回复的高分辨率图片，图中或报告中给出单位、样本量、误差线含义和 caption；
- `tables/`：每个汇总图和主结果表对应的机器可读 CSV，不允许只有图片而没有作图数据；
- `archive_manifest.json`：记录 experiment ID、Git commit、数据/config/code 哈希、证据范围、locked test 与 external-independent 是否开启、图表到源数据的映射，以及归档文件 SHA256；
- `README.md`：归档入口和复现命令。

大型逐行预测、checkpoint 和原始数据继续放在 Git 忽略的 `outputs/`，归档通过路径和 SHA256 引用它们。报告必须同时展示预登记主模型、基线、未通过门槛的候选、关键分层、失败率和不确定性，禁止只挑选有利结果。数据、代码或结论发生实质变化时使用新版本重建归档；旧证据不得静默覆盖。完成状态由 `scripts/verify_experiment_archive.py` 校验，实验记录中的 `artifacts.reviewer_archive.verification_status` 必须为 `verified`。

## 8.2 已完成的工程基准（2026-09-05；不用于模型定论）

NACCOM 1/8° 的 fCO2-only 大型 ST-Transformer 已完成一次可复现运行：`D=96`、3 个空间层 + 3 个时间层、12 个月窗口、Gaussian head、5 个 bootstrap 成员、每 epoch 轮换 8,192 个海岸格点、最多 80 epochs（实际早停分别为 60/79/41/36/47 epochs）。最终推理以 8,192 格点分块进行，完整覆盖每个评分集合，而不是沿用训练 tile。

| 集合 | N | RMSE (µatm) | MAE (µatm) | bias (µatm) | 真 R² |
|---|---:|---:|---:|---:|---:|
| training fit | 158,132 | 26.46 | 16.74 | +0.78 | 0.727 |
| development | 38,949 | 27.95 | 17.64 | -2.51 | 0.637 |
| test 2004–2005 | 13,052 | 24.48 | 14.51 | -1.65 | 0.615 |
| internal spatial challenge | 81,836 | 39.38 | 21.81 | -3.70 | 0.157 |

产物为 `outputs/experiments/st_full/metrics_summary.csv`、`prediction_fco2.npy` 和 `test_and_spatial_challenge.png`。此结果只比较 fCO2 单任务；空间挑战是内部地理留出，**不是**外部独立验证。它相对先前小型 ST 的时间测试 RMSE（25.69 → 24.48 µatm）有所改善，但空间挑战更差（38.68 → 39.38 µatm），故没有达到“骨干改善已被证实”的判断标准，更不能据此支持联合 TA/DIC/SSS 方案。
