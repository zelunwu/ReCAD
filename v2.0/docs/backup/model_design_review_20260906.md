# ST-Transformer 设计与训练审计（2026-09-06）

结论：现有证据不能认定主要瓶颈是参数量不足。先修正训练/数据配置的一致性，再做点估计损失、有效样本训练预算和局地解码器的受控实验，最后检验扩大主干的收益。现有运行完成了其配置下的训练，但不是充分调优或完整多变量反演。

审计读取当前源码、prepared 数据元信息、training/development masks、5 个保存的检查点与历史；没有重新打开 test/空间挑战标签做选择。样本曝光次数由当前确定性采样实现重建，旧运行未保存逐步样本日志，不能替代带代码/数据哈希的原始运行清单。

## 1. 实际模型

- 输入物理通道：SST、SSS 背景、ADT、pCO2air、wspd；另有经纬度、月份周期项和缺测标记。
- 输出 fCO2 均值及 Gaussian 方差；TAest、TA/DIC/SSS 输出、化学项均未接入本轮模型。
- 本质仍是带时空环境上下文的回归器，没有将稀疏观测作为推理输入进行场同化。
- 96 维、8 heads、空间 3 层、时间 3 层，共 **690,530** 参数。空间/时间主干各 334,656；cell embedding 1,440；head 18,722。
- 约 97% 参数在主干，逐格点支路和输出头约 2 万参数。cell embedding 是线性层，融合后 head 仅一个 GELU 隐藏层。
- **实际 patch 是 8×8（1°），不是 YAML 的 16×16（2°）**：`load_prepared` 使用 NetCDF 的 patch_size 属性；当前 CLI 没有根据训练 YAML 重建它。实际 active tokens=1,077；若 16×16 则为 340。
- 每个 patch 仅含背景均值和合并 coverage；fine-scale 原始背景仍进入 cell branch，因此并非所有细节都被平均删除，但邻域形态、梯度和锋面没有进入一个可学习的高分辨率编码器。
- 默认按自然年构造一个 12 月窗口，无法跨年 attention；无显式绝对年份输入，年际信息来自当年的背景场（包括 pCO2air）。
- 经纬度 positional encoding 在归一化坐标上使用频率 1 到约 1e-4，侧重宽尺度位置；是否限制局地表示需要消融，不能直接认定为主因。

最后一行占比很小，不足以解释整个误差差距；曝光次数显示预算有限，但也不能据此断定延长训练必然改善泛化。

确定的实现/口径问题：

1. **Bootstrap 不符合定义**：`_bootstrap_year_repeats` 只返回抽中的年份，dataset 的 `.get(y, 1)` 又保留未抽中的年份。每成员本应 22 个抽样窗口，实际为 32–35 个窗口。所有有效 training 年份都参与，各年重复权不一致。当前代码未将成员 seed 传给 dataset，所有成员也共享同一格点抽样序列。
2. **训练目标与主指标不同**：小模型 MSE，大模型 Gaussian NLL。NLL 中均值梯度为 `(mu-y)/variance`，学到较大方差可减小难点的均值梯度；这是一种潜在机制，不是已证实主因。当前检查点和早停确实监控 RMSE，先前称其按最低 NLL 选择的说法不准确。
3. **隐含按年份加权**：一个年度 batch 内对有效点平均，每个年度 batch 做一次更新。1998 年 95 个标签，2017 年 11,904 个标签，批内平均和重复采样使优化权重不同于最终所有格月等权 RMSE。等年权未必不合理，但必须与科学评分目标一致并明确记录。
4. **完整开发集没有参与 checkpoint 选择**：仅固定 10,531 个标签参与早停；可用分块全 dev 评分替换。不能因某轮验证震荡就断言模型容量不足。
5. **训练曲线不足以诊断 train RMSE 收敛**：历史记录 sampled Gaussian NLL，没有固定训练集 eval-mode RMSE、学习率、有效标签数、梯度范数。NLL 下降与均值 RMSE 持续下降不是同一件事。
6. **coastal mask 是观测足迹**：构建脚本按任一年 SOCAT `n>0` 定义 mask，不是独立地理海岸/陆架 mask。100% 评分覆盖仅表示已定义评分集合完整，并不代表覆盖所有未观测海岸格点。
7. **token coverage 实现与注释不同**：分母统计整块格点；聚合前未显式使用 coastal mask；各通道 coverage 取 max，且缺少逐通道 token 缺测信息。应明确聚合邻海背景还是仅海岸背景，并统一实现。
8. **统计量持久化不完整**：CLI stats 加载只恢复预测因子统计，不恢复 target mean/std；本轮缺文件而重新 fit，故不能把此问题当成本轮失败原因，但后续复现/推理必须同时保存和加载两者。

训练曲线：`outputs/experiments/st_audit_20260906/training_diagnostics.png`。多个成员后期 NLL 仍降低、dev RMSE 已震荡或回升。因此“只要继续更多 epoch”缺乏支持。

## 3. 优先实验

所有新方法只在 training/dev 上选择；此前已经反复查看的时间测试、空间挑战不再当作新一轮盲集。真正外部独立验证仍需冻结来源、跨库去重和谱系审计。

### P0：修正并固定实验口径

- 校验/显式设定 effective patch size；保存 grid、split、代码/数据哈希与全部归一化参数。
- 修正 bootstrap，诊断阶段先用全 training pool、单成员；ensemble 最后进行。
- 地理 mask 与标签 mask 分离；明确 token 聚合范围和逐通道 coverage。
- 全量分块 dev 选 checkpoint；记录固定 train/dev RMSE、NLL、学习率、有效标签曝光、gradient norm、optimizer steps。

### P1：先检验现有模型是否能优化到位

1. 固定 training 子集约 1,024–4,096 个格月标签，MSE、关闭 dropout/weight decay、关闭 bootstrap、无早停，充分重复训练。目的仅为拟合与梯度诊断，不作为科学评分；先检查相同模型输入是否对应冲突标签。若训练误差仍远高于 RF，排查输入、梯度、优化器和解码器。
2. 保持 D96/3+3 与 effective patch8，改 MSE；使用包含训练观测的 cell/year 采样或完整标签分块遍历。为降低开销只解码监督位置、保留背景 token，并明确目标采样权重。
3. 在这一统一训练条件下，用 LR=1e-4/3e-4/1e-3 的小型预登记开发网格；预算按 optimizer steps 和标签曝光数报告。保存当前约 2k steps 和延长后的 5k/10k 诊断点（开发表现决定是否继续）。增加预算和学习率搜索是候选实验，不是已验证最优值。
4. 若需要概率输出，在均值拟合后再校准方差；联合 NLL、MSE warm-start 或 beta-NLL 用 dev 比较。不要把未知方差等同于实际观测误差。

### P2：优先增加局地表达能力

建议结构：`fco2_hat = g_local(cell fields, local neighbourhood, time) + delta_context(ST features)`。

- `g_local` 用宽度 128–256、3–4 层残差 MLP；先独立训练，再联合微调。delta 支路最后层零初始化或带可学习小门控，保证起点保留已训练局地模型表现。
- 必要时用小型 masked CNN 编码 3×3/5×5 环境邻域或学习式 patch embedding；把细尺度梯度与海岸几何保留给解码器。
- 同一批背景信息上检验当前时间模块与跨年窗口（如前后 6 月）的差异；新增变量、时间编码与结构变化分开消融。
- 新变量优先依据独立来源可用性比较 bathymetry、距岸、Chl-a/河流背景等；TAest 在后续多任务/先验实验中统一加给各骨干。

### P3：最后做参数量实验

固定架构与损失、训练样本权重、调参机会、成员数和验证方法，比较：

| 宽度 | 当前 3+3 架构参数量 |
|---|---:|
| D96 | 690,530 |
| D192 | 2,745,026 |
| D256 | 4,872,450 |

参数量不包括五成员数量的乘法作为单模型容量。先按相同标签曝光数比较，再报告相同算力预算的次级比较。扩大 token 数时 attention 内存近似随 P² 增长；局部/多尺度 attention 或 fused SDPA 用于提高吞吐，不能作为准确率保证。

判断规则：同模型优化改进有效则支持优化瓶颈；相近预算下加宽局地头有效则支持参数分配/局地表示瓶颈；统一训练后扩大主干同时改善 train 与 dev 才支持主干容量不足；只改善 train 则不支持外推收益。输入增加改善 dev 而扩容无改善，才更支持信息不足。

## 4. 对前次解释的修正

v1.1 和 v2 的 training 分数都属于在 training 标签上重代入评估，后者不是天然更诚实。train/dev 差距小同时可能来自欠拟合；随机验证有相关性也不能未经数据审计直接定性为标签泄漏。当前 ST 保留每格原始背景输入，因此不能把误差全部归因于 patch 平均。v1.1 表中 R² 是带截距 OLS 对应的 Pearson r²；应与 v2 的 0.627 对照，而不是直接与真 R²=0.615 对照。

方法参考：Seitzer et al., 2022, https://arxiv.org/abs/2203.09168（Gaussian NLL 优化风险）；Gorishniy et al., 2021, https://arxiv.org/abs/2106.11959（残差 MLP 与 Transformer 的受控表格回归基准）。文献不能替代本项目的验证结果。
