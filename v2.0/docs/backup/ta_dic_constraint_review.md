# TA/DIC 约束策略评估与改进建议

*生成于接手审计(2026-09);基于对 `outputs/experiments/` 22 个实验目录、
GLODAP 锚点空间支持度实测、以及 st_full/st_small/joint_* 系列结果的复核。*

## 0. 结论先行

**你的判断被数据完全证实,而且比预想的更极端:**

| 事实 | 数值 |
|------|------|
| 全球 0.125° 沿海格总数 | **148,795** |
| 其中有 TA/DIC 观测锚点的 | **2,157(1.4%)** |
| **完全没有任何 TA/DIC 观测的沿海格** | **146,638(98.6%)** |
| 美国东岸(275–300°E, 20–50°N)覆盖 | 376/10,790 = **3.5%**(45 航次) |
| 美国西岸(225–250°E, 24–50°N)覆盖 | 284/8,523 = **3.3%**(52 航次) |
| GLODAP 5m 锚点总量 | 14,930(592 航次,1993–2021) |

**结论**:
1. **全球范围用 CO2SYS 硬约束没有意义** → 98.6% 的格没有任何 TA/DIC 观测,
   顶层约束只能"约束空气"(模型自由度在无观测区任意取值都满足化学闭合)
2. **美国沿岸也谈不上"数据多"** → 覆盖仅 3.3–3.5%。
   虽然相对全球密集(锚点数占全球 13.5%),但对**逐格训练**而言仍是极稀疏锚
3. **唯一正确的用法**:把 TA/DIC 当作**区域化、稀疏锚定的诊断量**,而非全球自由度

## 1. 上一轮策略的实测效果(为什么现在的做法不够好)

`experiments/joint_four_full_20260907/analysis_report_zh.md` 的 B1/B2 对照:

| 指标 | B1(无化学损失) | B2(软 CO2SYS) | 变化 |
|------|---------------|--------------|------|
| Independent fCO2 RMSE | 23.404 | 23.291 | **-0.48%** |
| Independent SSS RMSE | 1.159 | 1.155 | -0.37% |
| Independent DIC RMSE | 37.127 | 35.862 | -3.41% |
| Independent TA RMSE | 38.814 | 38.635 | -0.46% |
| **化学闭合误差(独立 SOCAT)** | 25.54 µatm | **2.05 µatm** | **-92%** |

**这是最重要的一条证据**:
> **闭合误差改善 92%,但独立预测技能只改善 <0.5%。
> CO2SYS 是约束(constraint),不是观测(observation)。**

它消除了四个输出头之间的**自由补偿漂移**(这是有价值的——DIC/TA 不再互相乱补偿),
但**没有创造任何缺失的信息**。在没有 TA/DIC 观测的地方,化学闭合只是把不确定性
从一个变量搬到另一个变量。

### 其它实测缺陷

| 问题 | 证据 |
|------|------|
| **TA 独立验证失败** | 东岸 C2 TA 在 2004–05 独立集 **R² = -0.235**(负!),RMSE 46.06;只有 38 个锚点/3 航次 |
| 西岸 TA 跨航次不可用 | 航次 CV RMSE **74–126** µmol/kg vs internal test 39(随机 test 严重乐观) |
| TA 区间校准差 | 东岸 90% 区间覆盖:train 96.1% → internal test 71.7%(域外明显过窄) |
| 时间模块受限 | 每年独立 12 个月 attention,34 年数据未形成跨年序列 |
| 任务竞争 | TA/DIC 的 seed 波动 >> fCO2/SSS(稀疏任务被密集梯度牵引) |
| **月场 vs 瓶样代表性** | GLODAP 单次瓶样被当作月场标签 → TA/DIC RMSE 存在**结构性下限** |

## 2. 建议的方法改进(按优先级)

### 🔴 P0 — 承认并显式化"约束的空间有效性"

**把全局统一的化学损失改为空间掩膜的化学损失**:

```python
L_chem = Σ_x w(x) · (CO2SYS(T,S,TÂ,DIĈ) − fCO2̂)²

w(x) = 1.0   在 TA/DIC 有观测支持的格(1.4% 全球、3.3-3.5% 美国沿岸)
     = 0.1   在无锚点但仍属同水团的邻近格(空间衰减)
     = 0.0   在完全无支持的远洋/无观测区
```

**理由**:当前对全部 148,795 格施加同等化学闭合,等价于在 98.6% 的区域做
"无观测约束下的奇异解选择"——这些区域的 TÂ/DIĈ 组合有无穷多解,模型只是
被推到一个任意解上,并把误差反射到 fCO2 头。

**实施**:用 GLODAP 锚点生成 `chem_support.nc`(0.125°,含 `n_anchors`、
`distance_to_nearest_anchor`),损失按距离衰减加权。

### 🔴 P0 — DIC 降级为派生量(上一轮已做对,应固化)

上一轮 9-09 的最终协议已经是:
```
独立预测: SSŜ, fCO2̂, TÂ
DIĈ = inverse_CO2SYS(T, S, TÂ, fCO2̂)   ← 可微逆解码器
```
这消除了 DIC/TA 自由度冗余。**继续保持**。
(实测:逆解码器宽域 RMSE 0.552 µmol/kg,exact 闭合 0.31–0.45 µatm,足够)

### 🟠 P1 — TA 改用"区域+航次级"训练与验证

既然 TA 支持只有区域性的稀疏锚:

| 做法 | 说明 |
|------|------|
| **放弃全局 TA 头** | 全球模型只输出 SSS/fCO2(+派生 DIC,标记"低置信") |
| **区域 TA 专题** | 美国东西岸(或按水团分区)单独训练 TA 头(上一轮 C1/C2 已试) |
| **航次级 CV 作为唯一可信指标** | 禁用随机点 test(西岸随机 test RMSE 39 vs 航次 CV 74–126,严重乐观) |
| **损失先航次内平均再航次等权** | 防止高密度航次(如东岸 45 航次中的少数)主导 |

### 🟠 P1 — 残差参数化(而非直接回归)

```
TÂ = TA_ESPER(SSS,SST,lon,lat) + δTÂ      # ESPER 方程16 已移植,实测 ΔTA/ΔS≈60-70
SSŜ = SSS_GLORYS + δSSS
DIĈ = DIC_chem_baseline + δDIĈ
```
实测依据:ESPER TAest 输入 baseline RMSE 73.4(偏差 -62.2),模型把偏差修掉
后降到 38.6——**说明大尺度结构该由先验提供,模型只学残差**。
(注意:δ 头必须允许低频偏差,不能强零中心正则)

### 🟡 P2 — 时间上下文(结构性短板)

当前每年 12 月窗口 → 改 **36 或 60 个月滑动窗** + 绝对年份编码。
这是 "ST-Transformer" 名义能力与实际能力的最大差距(见 §1)。

### 🟡 P2 — 独立验证数据的真实缺口

**当前没有真正的外部独立验证**:
- 2004–05 是**时间留出**,仍来自 SOCAT/GLODAP 原库(与训练同源谱系)
- TA/DIC 独立集仅 **38 个锚点/3 个航次** —— 统计上不支撑任何强结论
- **必须补**:CODAP-NA(NCEI 503 屏蔽中;服务器 watchdog 已部署)、
  或 GLODAP 里未进入 Carter 系数谱系的航次(按 expocode 核验)

## 4. 一句话给论文的定位建议

> **主产品**:SSS / fCO2(全球 1/8°,技能可靠)
> **专题产品**:美国沿岸 TA(区域化、航次级验证、明确报告样本数与区间)
> **派生量**:DIC 与其它碳酸盐参数(由 T+S+TA+fCO2 经 CO2SYS 导出,标注为诊断量)
> **不使用**:全球统一化学硬约束(无观测支持区会引入伪约束)
